9. TOOLS AND SAFE PUBLICATION PROCEDURE

Bundle edit (fingerprinting):
  1. Copy the active bundle and make the narrow edit.
  2. Name it js/<name>.<sha256[:8]>.js.
  3. Update the single reference in index.html; keep the old file.
  4. Run node tests/asset-fingerprints.mjs plus the related suites.

Push: git push origin codex/profit-readiness (GitHub credential). A push triggers an automatic Preview build.

Production rebuild (Vercel CLI with --token "$VERCEL_TOKEN" --scope willsep200-9430s-projects, run from a linked dir such as /tmp/vc):
  vercel ls cardresell -m githubCommitSha=<full sha>        → Preview URL for that commit
  vercel redeploy <preview-url> --target production          → rebuild for Production (never "Promote")
  vercel inspect https://www.cardresell.org                  → confirm the new dpl id is Ready
  Then curl / and the changed bundles and cmp them against local files. The CDN can return 000 or old bytes for 1–3 minutes, so retry before concluding anything.

Logs: vercel logs --project cardresell --environment production --no-branch --no-follow --since <ISO> -n 300 --json
  - Lines appear about 4x duplicated; dedupe them.
  - PROVIDER_USAGE lines carry provider/mode/tokens/duration.
  - '[capture-meta]' lines carry sharpness scores.
  - Logs can lag a few minutes; one OpenAI line for the 05:10Z grade had not appeared at check time.

Env: vercel env add NAME production --value "$V" --sensitive --force --yes.
  Sensitive values pull back empty. A literal "\n" in a pulled file is a display artifact, not a fault.

The Firebase connector covers Firestore only; Production has no Firebase admin credentials.
