# Collection, Flips and Drafts usability

Collection empty state offers Find a card (focuses lookup) and Add manually. Drafts offers sign-in when needed and a direct scanner route when empty. Selected main navigation now exposes aria-pressed. Collection has a heading explaining the Drafts path; the draft heading action says Choose a card to match its destination.

Clear collection moves into More, retaining existing confirmation. Everyday buttons have 44px minimum heights. Flips sign-in and collection membership copy no longer use outdated Pro/unlimited language or promise a five-second sign-in.

Validation: brand UI browser 398 passed over light/dark and four viewports; draft-list-screen 102; draft-card-actions-browser 88; draft-delete-browser 113; asset fingerprints 105. Tests use isolated fixtures; no customer credits or paid inference.
