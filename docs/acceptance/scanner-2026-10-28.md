## Deployment incident and recovery

PR149's first deployment built successfully but /api/scan failed at module startup (HTTP500 FUNCTION_INVOCATION_FAILED). The new module used import.meta URLs, incompatible with this repository's deployed CommonJS handling. All 14 initial attempts failed without credit deductions. Commit6f51c6a replaced that loader with bounded fetches of pinned public catalogue assets. The deployed endpoint then returned the expected HTTP405 for GET, and authenticated photo scans ran normally.

The initial unit/build checks did not cover deployed module startup. Future releases must exercise the deployed /api/scan endpoint before paid photo acceptance.
