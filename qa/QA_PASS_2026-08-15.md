## Fixed & deployed

### 🔴→✅ Paid TCGPriceLookup API key was public (`56617c1`)
`window.CARDSELL_TPL_KEY = 'tcg_37ca6c...'` was hard-coded into `index.html` and served to every anonymous visitor. Anyone opening dev tools could grab the key and rack up charges on the Cardresell account.
**Fix:** New server endpoint `/api/tpl-proxy` reads `process.env.CARDSELL_TPL_KEY` and forwards allow-listed GET requests to `api.tcgpricelookup.com` with the header attached. Edge-cached 5 min for cost savings. Client no longer touches the real key. Search + pricing behavior unchanged.

### 🟠→✅ `/about` and `/contact` silently served the main app (`a2fcbdf`)
Both HTML files existed locally but weren't listed in `vercel.json` builds/routes, so the SPA catch-all redirected them to `index.html`. Any SEO backlink or direct link would land users on the wrong page.
**Fix:** Registered both files in `vercel.json`. Verified: `/about` now returns the "About · CardResell" page.

### 🟠→✅ PWA manifest was disabled (`ec71a94`)
`<link rel="manifest">` was commented out in `index.html` because `/manifest.json` was returning HTML (SPA catch-all). The actual `manifest.json` file exists in the repo.
**Fix:** Added `manifest.json` to `vercel.json` builds/routes and re-enabled the link tag. Verified: `/manifest.json` now returns `application/json`.

### 🟠→✅ 35 broken toast calls (`ec71a94`)
`showToast(msg, 'info')` and similar type-string calls at 35 sites caused `setTimeout(..., 'info')` → coerced to NaN → toast disappeared instantly.
**Fix:** `showToast(msg, arg)` now accepts either a duration number or a type name and falls back to the default 3.5s duration when a string is passed. Also applies a `toast-<type>` CSS class so those calls can style differently later.

### 🟠→✅ Bulk-edit rename silently reverted MTG/YGO/Lorcana cards to Pokemon (`ec71a94`)
`bulkEditCardName()` called `_bulkFetchPrice(name, set, number)` without passing `cardType` or `isJapanese`, so a renamed Magic card would re-price against the Pokemon TCG API and show "Price unavailable".
**Fix:** Pass `result.cardType` and `result.isJapanese` through so multi-TCG routing works after rename.

### 🟠→✅ Portfolio + P&L table crashed on legacy entries (`ec71a94`)
`p.buyPrice.toFixed(2)`, `p.currentValue.toFixed(2)`, `f.profit.toFixed(2)` all threw `TypeError: Cannot read properties of null` when any entry had a missing/null price field. Blank table for that user forever.
**Fix:** Every numeric field now goes through a `num()` helper that coerces to a safe number (0 if NaN/null).

### 🟡→✅ 3 mobile-hostile prompts (`ec71a94`)
- `bulkEditCardName()` used `window.prompt()` — now uses new `promptInline()` overlay
- `bulkEditPrice()` used `window.prompt()` — now uses `promptInline()`
- `showToast(...)` call sites passing type strings (see above)
**Fix:** New `promptInline(label, default)` returns a Promise, renders a styled overlay with Enter/Esc/click-outside handling.

### 🟡→✅ 2 mobile-hostile alerts (`a2fcbdf`)
`alert()` was used for empty-search / empty-name guards at `index.html:4116` and `index.html:5984`. iOS renders these as blocking browser dialogs.
**Fix:** Both converted to `showToast()`.

### 🟡→✅ Landing headline undersold multi-TCG support (`a2fcbdf`)
"Search any Pokémon, sports, or trading card" now reads "Search any Pokémon, Magic, Yu-Gi-Oh, Lorcana, or sports card".

### 🟡→✅ eBay sold-comps empty state reads as "this card doesn't sell" (`ec71a94`)
Reworded from "No recent sales found · View eBay sold →" to "See sold comps on eBay →".

## Flagged but not fixed (product decisions)

### 🟡 Social-proof counter is fabricated
`index.html:4339-4341` — "X,XXX searches so far" grows via a deterministic `daysSinceLaunch × 48` formula, not real data. Anyone inspecting the page sees the fake counter. Reddit's technical crowd will notice.
**Options:** (1) leave it (low actual risk pre-launch), (2) replace with a real `/api/stats` counter, (3) remove the badge entirely. Not touched — this is a product decision.

### 🟡 `stripe-checkout` vs `stripe-annual-checkout` use different auth models
Monthly uses body `userId`; annual uses Bearer token. Both currently work. Also, monthly reads `STRIPE_PRICE_ID` from env but annual hardcodes `price_1TosPSFW2YZoedIZ5e0abG3y`. Consider unifying before adding more plans.

### 🟡 Fabricated review count on About page + old-timer "no bugs" claims
Didn't audit About page copy end-to-end; skim it before launch to make sure no numbers there are made up.

## Known limitation

### ⚠️ eBay blocks server-side sold-comps fetch (403 to Vercel IPs)
`/api/ebay-sold` scrapes eBay's public search HTML; eBay returns 403 to datacenter user-agents, so median/avg comp values are almost always empty. The client falls back to a direct "See sold comps on eBay →" link (post-fix). Long-term proper fix: use the official eBay Browse API — the Vault credential `custom-cred:api.ebay.com` currently 401s and needs a fresh token.
