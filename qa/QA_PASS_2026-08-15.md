## Findings

### 🟠 MAJOR — `/about` and `/contact` silently serve main app (index.html)
**Location:** `vercel.json`
**Impact:** Direct URLs, SEO backlinks, sitemap crawlers all get the main app instead of the actual pages. Neither page is exposed in the current UI (About opens modal, Contact is mailto), but any external link would look broken.
**Fix applied:** Added `about.html` + `contact.html` to `builds`, added `/about` + `/contact` routes.
**Status:** Fix ready, pending deploy.

### 🟡 MINOR — 2 `alert()` calls used for validation (mobile-hostile)
**Location:** `index.html:4116` (sports empty search), `index.html:5984` (collection empty name)
**Impact:** iOS Safari shows the browser's ugly native alert dialog instead of the app's `showToast`.
**Fix applied:** Converted both to `showToast(...)`. Pending commit.

### 🟡 MINOR — Landing headline copy still says "Pokémon, sports, or trading card"
**Location:** `index.html:1983`
**Impact:** Under-sells the new MTG / YGO / Lorcana support.
**Fix applied:** Updated to "Pokémon, Magic, Yu-Gi-Oh, Lorcana, or sports card".

### 🟡 MINOR — Social-proof counter is fabricated
**Location:** `index.html:4339-4341` (`LAUNCH_TS + daysSinceLaunch * 48`)
**Impact:** "X,XXX searches so far" grows deterministically off a formula, not real data. Anyone who inspects the page will see the fake counter. Not urgent for launch, but consider replacing with real counter or removing.
**Status:** Flagged — no fix applied.

### 🟡 MINOR — `stripe-checkout` vs `stripe-annual-checkout` use different auth models
**Location:** `api/stripe-checkout.js` reads `body.userId`; `api/stripe-annual-checkout.js` verifies Firebase token from Authorization header.
**Impact:** Works today — client already sends both formats correctly. But two paths = double the failure surface for future changes.
**Status:** Flagged — no fix applied.
